VPS

Wired in Phase 3.

This page will pull live stats from the Contabo host on each page load (no background poller, no extra agent — just SSH against the existing contabo-vps alias):

  • CPU — load avg + per-core utilization (top -bn1 / /proc/stat).
  • Memory — free -m with used / cached / available.
  • Storage — df -h per mount, plus docker system df for image/volume usage.
  • Network — ss -s connection summary; recent Caddy access log entries (docker exec rndexpart-gateway cat /var/log/...).

Implementation will live in a new app/vps.py module that shells out to tools/rndexp vps exec "<cmd>" via subprocess (the dashboard container will be granted the same SSH key the CLI uses, mounted read-only).
