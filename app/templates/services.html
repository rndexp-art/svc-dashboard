Services

Wired in Phase 3.

One row per service in config/services.yml, sourced from:

  • Status — docker ps on the VPS, filtered to the service container.
  • Version pin — submodule SHA on production (git ls-tree).
  • Recent deploys — last 10 runs of deploy-gateway.yml via the GitHub Actions API, plus recent commits on the submodule's production branch.
  • Logs — last N lines from docker compose logs <svc> on the VPS, with a "tail" toggle that opens an SSE stream.
