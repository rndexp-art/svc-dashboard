Users

Wired in Phase 2.

This page will list every user, let an admin grant/revoke roles, send an email invite (with a link the invitee uses to set a password), trigger a password reset, and delete an account — with a guard that blocks deleting the last user holding the admin role.

Backed by new JSON endpoints on svc-auth: GET /api/users, POST /api/users/invite, DELETE /api/users/{id}, POST /api/users/{id}/reset-password, POST /api/users/{id}/roles / DELETE /api/users/{id}/roles/{slug}.

The svc-auth change set also adds password login + invite redemption + password reset to the auth service itself.
